# Robotics notes

Working notes from commissioning two Unitree robots at STEM Innovation Academy in Calgary: a Go2 quadruped (Kepler) and an R1 humanoid (Vera).

Live site: https://stem-ia.github.io/robotics/

- `kepler/` How I deployed a locomotion policy trained in Isaac Lab onto the Go2, step by step.
- `vera/` Bringing up the R1 humanoid from an uncommissioned compute module to a scripted arm and hand routine.
- `isaac-sim-blackwell/` The Isaac Sim 5.1 crash on RTX 50-series cards with 595.xx drivers, and the fix.

Written by Ben Wood, Digital Learning Coordinator, STEM Innovation Academy.
